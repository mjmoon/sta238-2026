An estimator \(T\) is called an unbiased estimator for the parameter \(\theta\) if

\[\mathbb{E}(T)=\theta\]

irrespective of the value of \(\theta\).

The difference \(\mathbb{E}(T)-\theta\) is called the bias of \(T\); if the difference is nonzero, then \(T\) is called biased.

Mean squared error

We can use the mean squared error to compare efficiency of estimators.


Let \(T\) be an estimator for a parameter \(\theta\). The mean squared error of \(T\) is the defined as

\[\text{MSE}(T)=\mathbb{E}\left[\left(T-\theta\right)^2\right].\]

Why MSE?

  • It’s the expected value of squared distance of the estimator from the parameter, or the error.
  • The smaller the mean squared error, the more efficient an estimator.

Why MSE?

  • It accounts for both the bias and the variance of an estimator.

\[\begin{split} \text{MSE}(\widehat{\theta}) &= \mathbb{E}\left[\left(\widehat{\theta}-\theta\right)^2\right] \\ &= \text{Var}\left(\widehat{\theta}-\theta\right)+\left[\mathbb{E}\left(\widehat{\theta}-\theta\right)\right]^2\\ &= \text{Var}\left(\widehat{\theta}\right)+\left[\text{bias}\left(\widehat{\theta}\right)\right]^2 \end{split}\]

Given two estimators, \(T_1\) and \(T_2\), for a parameter \(\theta\), we can say \(T_1\) is a more efficient estimator when

\[\text{MSE}(T_1)<\text{MSE}(T_2)\]

irrespective of the value of \(\theta\).

Efficiency of estimators

Given two estimators, \(T_1\) and \(T_2\), for a parameter \(\theta\), we say \(T_1\) is a more efficient estimator when

\[\text{MSE}(T_1)<\text{MSE}(T_2)\]

irrespective of the value of \(\theta\).

\[\implies \text{MSE}(\widehat{\theta})=\text{Var}\left(\widehat{\theta}\right)\iff \text{bias}\left(\widehat{\theta}\right)=0\]

Efficiency of estimators

Given two estimators, \(T_1\) and \(T_2\), for a parameter \(\theta\), we say \(T_1\) is a more efficient estimator when

\[\text{MSE}(T_1)<\text{MSE}(T_2)\]

irrespective of the value of \(\theta\).

Given two unbiased estimators, \(T_1\) and \(T_2\), for a parameter \(\theta\), we say \(T_1\) is a more efficient estimator when

\[\text{Var}(T_1)<\text{Var}(T_2)\]

irrespective of the value of \(\theta\).

\(\cfrac{\text{Var}(T_1)}{\text{Var}(T_2)}\) is called the relative efficiency of \(T_2\) over \(T_1\).

Example: Is \(T_2\) more efficient?

lambdas <- seq(7) # irrespective of lambda values
bias_t1 <- numeric(7)
bias_t2 <- numeric(7)
var_t1 <- numeric(7)
var_t2 <- numeric(7)

m <- 1000  # number of estimates for each lambda
n <- 100   # sample size for each estimate

for (lambda in lambdas) {
  t1 <- numeric(m)
  t2 <- numeric(m)
  for (i in seq(m)) {
    sales <- rpois(n, lambda)
    t1[i] <- mean(sales == 0)
    t2[i] <- exp(-mean(sales))
  }
  bias_t1[lambda] <- mean(t1) - exp(-lambda)
  bias_t2[lambda] <- mean(t2) - exp(-lambda)
  var_t1[lambda] <- var(t1)
  var_t2[lambda] <- var(t2)
}

Recall: The Central Limit Theorem

  • We say, \(Z_n\) converges in distribution to \(Z\sim{N}(0,1)\). That is, \[Z_n\overset{d}{\to}Z\quad\text{where}\quad Z\sim{N}(0,1).\]


Let \(X_1,X_2,...,X_n\overset{i.i.d}{\sim}F\) for any distribution \(F\) with a finite mean \(\mu\) and a finite variance \(\sigma^2>0\). Then

\[\lim_{n\to\infty}P(Z_n\le a)=\Phi(a)\]

where \(Z_n=\sqrt{n}\frac{\overline{X}_n-\mu}{\sigma}\) and \(\Phi(a)\) is the cumulative distribution function of the standard normal distribution.

Equivalently, we have \[\lim_{n\to\infty}P(\overline{X}_n\le a)=P(Y\le a)\] where \(Y\sim{N}\left(\mu, \frac{\sigma^2}{n}\right).\)

Sampling distribution of the sample proportion

  • \(n\widehat{p}_n\) follows a binomial distribution.
  • In practice, we approximate the distribution with a normal distribution based on the CLT when \(n\) is sufficiently large.

\[\widehat{p}_n\overset{\cdot}{\sim} N\left(\widehat{p}_n, \cfrac{\widehat{p}_n(1-\widehat{p}_n)}{n}\right)\]

When can we assume it’s reasonable to apply the CLT?


Consider an event \(A\) in the sample space of a random experiment with \(p=P(A)\). Let \(N_A\) be the number of times \(A\) occurs when the experiment is repeated \(n\) independent times.

\[\widehat{p}_n=\frac{N_A}{n}\] is an estimator for \(p\) with

  1. \(\mathbb{E}(\widehat{p}_n)=p\);
  2. \(\text{Var}(\widehat{p}_n)=\frac{p(1-p)}{n}\); and
  3. \(\widehat{p}_n\overset{d}{\to}Y\), where \(Y\sim{N}\left(p, \cfrac{p(1-p)}{n}\right)\).

Summary

  • You can assess the quality of an estimator with respect to its target parameter based on bias, MSE or efficiency, and consistency.

  • To assess the qualities, you need to study the sampling distribution.

  • When we have a sufficiently large sample, we can approximate the sampling distribution for sample means based on the CLT

\[\widehat{p}_n\overset{\cdot}{\sim} N\left(\widehat{p}_n, \cfrac{\widehat{p}_n(1-\widehat{p}_n)}{n}\right)\]

for a proportion \(p\), and more generally,

\[\widehat{\theta}=\overline{X}_n\overset{\cdot}{\sim} N\left(\overline{X}_n, \cfrac{\sigma^2}{n}\right)\]

for a population mean, \(\theta\).
